O projektu Pokédex

Webová aplikace vyvíjená na frameworku Python Flask & Bootstrap 5

Co je tento projekt?

Tento Pokédex slouží jako interaktivní katalog Pokémonů. Projekt vznikl za účelem demonstrace čistého propojení backendového Python frameworku Flask, šablonovacího systému Jinja2 a responzivního UI postaveného na Bootstrap 5 s vlastním úpravami (CSS overrides).

Všechny styly využívají retro-futuristický design ikonického červeného Pokédexu včetně charakteristické svítící LED čočky, tmavého rozhraní obrazovky a barevně odlišených typů jednotlivých Pokémonů.

Technologický stoh

  • Backend Python (Flask)
  • Templating Jinja2
  • CSS Framework Bootstrap 5
  • Vlastní CSS style.css
